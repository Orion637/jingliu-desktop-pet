# 镜流桌宠 · 完整整合版

双击 `JingliuPet.exe` 启动，保留整个 `_internal` 文件夹。旧的阶段 1 压缩包不是本次新版。

点击桌宠底部角标，或右键选择「设备电量 / DSH 状态」。动作预览中的同名按钮也可打开面板。左键互动、拖拽、双击动作预览、武器和全部 14 个动作继续可用。重复启动唤回现有实例。

单击人物会在 9 个明显的一次性动作中随机选择，并避免连续重复；不会随机进入持续拖拽、环顾、休息或待机循环。动作结束后平滑回待机，动作中再点击可以切换。预览中的人物也可这样点击；底部状态角标仍用于打开面板。

## ROG 棱镜 2

识别 USB 2.4GHz 接收器 `0B05:1AFA` 的已核实接口，每 15 秒查询电量，独立查询充电状态。未插接收器、耳机关闭或读取失败时显示 N/A。蓝牙模式和未经验证的其他 ROG 型号不套用这个协议。

## DSH

默认读取 `DSH_HOME`，未设置时使用当前用户的 `.dsh`。在「数据源设置」可修改主目录和 DSH 程序的完整路径。默认安装程序为 `E:\DeepSeek Harness\DeepSeek Harness.exe`。使用完整路径识别进程，避免把普通 Node/Python 程序误认成 DSH。

监听 `sessions` 中的 v4 `.jsonl` / `.jsonl.zstd` / `.jsonl.zst`，只读访问原文件，不启动或修改 DSH。当前轮次、步骤、工具、后台作业与确认状态来自实际事件边界。日志没有可靠的任务完成百分比，因此处理中显示不定进度，轮次结束后显示完成/出错状态。DSH 未运行时自动隐藏其进度区域，桌宠继续独立互动。

Token 仅计 canonical `assistant/message.data.usage`，按会话和回复 ID 去重，忽略重复的 stream usage；支持半行续写、压缩文件和文件轮转。今日按 Asia/Shanghai 统计，缓存输入单列并计入总量。会话累计请求 Token 可能很大，不能当成当前上下文大小或金额。历史日志分批索引，未完成时有提示。仅支持已核验的 v4 schema，其他版本不会猜测解析。

各个 DSH 主目录的统计缓存分开保存。损坏文件只跳过本文件；面板提示统计可能不完整。为限制扫描成本，最多覆盖最近 4,096 份日志，达到上限时明确提示较早日志未计入。

余额只请求 [DeepSeek 官方接口](https://api-docs.deepseek.com/api/get-user-balance/)，缓存成功和失败结果 60 秒，刷新按钮不会绕过缓存。支持本应用保存的 API Key、环境变量 `DEEPSEEK_API_KEY` 和 DSH 凭证中明确的明文 API-Key 引用；不把账户登录令牌、浏览器会话令牌或加密引用串当作 API Key。无法安全取得有效 Key 时显示 N/A，可在设置中输入。Key 用当前 Windows 用户的 DPAPI 加密保存，不写入 JSON、日志或进程参数，不随压缩包分发。

## 漫步者 G3M Pro

v1.1 已识别实机向 Windows 报出的 Telink / G3M PRO，接收器 `320F:706E`，IF1、`FF1C:0092`。使用经过独立资料和本机验证的只读电量查询，每 15 秒更新。不修改配对、灯光、DPI 或固件。鼠标必须切到 2.4G 模式并开机唤醒；仅插入接收器、使用蓝牙或鼠标关闭/休眠时可能显示 N/A。对未验证型号不套用此协议。

有效电量为 0–100%，不猜测或截断异常字节。不同来源对充电标志的非零值解释不一致，因此仅确认放电值 0，其他值显示充电状态未知。诊断保存在本机 `diagnostics/g3m.json`，不自动上传。MCHOSE G3 V2 不是此型号，不会套用 G3M 协议。资料和 MIT 许可见 `G3M电量协议与来源.md`。

## 全屏自动隐藏

默认启用。前台全屏游戏、视频或其他应用覆盖桌宠所在的显示器时，桌宠和底部角标自动隐藏，退出全屏或切回普通窗口后恢复，不抢占键盘焦点。正常最大化窗口、桌面、最小化窗口和其他显示器上的全屏不会触发本屏桌宠隐藏。检测约 0.5 秒一次，隐藏期间电量和 DSH 监控继续工作。

右键菜单的「全屏时自动隐藏」可关闭此功能，设置会保存。桌宠因全屏隐藏时，关闭动作预览不会退出桌宠进程。

## 状态与稳定性

角标统一显示独立待机、DSH 工作、电量低或数据源异常。低于或等于 20% 且未确认充电的有效电量触发低电量状态；离线的 N/A 不当成异常或 0%。每个数据源使用独立短期进程和超时，失败仅影响本项。退出时结束所有本应用启动的读取进程。

设置、轮转日志和缓存优先保存在程序旁，目录不可写时自动转到 `%LOCALAPPDATA%\JingliuPet\<安装标识>`。日志最大约 6 MiB，DSH SQLite 缓存上限约 128 MiB；不保存对话正文、工具参数或结果。程序设置窗口中的路径属于本机信息，不随交付包提供。

Windows/Qt 使用逻辑像素；屏幕移除、可用区域或 DPI 改变时会恢复桌宠可见位置。实际验证以本机屏幕为准，尚不能保证所有多屏/DPI 驱动组合。
